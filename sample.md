# Markdown Viewer Test Document

Welcome to **md-viewer**! This is an ultra-lightweight, zero-dependency Markdown viewer designed for GNOME / Ubuntu.

---

## Features
- [x] Zero heavy download (0 MB extra packages needed)
- [x] Instant startup (< 0.2s)
- [x] Supports system Dark / Light mode automatically
- [x] Full GitHub Flavored Markdown
- [x] Syntax Highlighting with Pygments
